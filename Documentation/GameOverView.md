# Game Overview

## Features: 
- Interactable Objects
- Highlight on interactable object when the action is available
- Doing certain object interactions allows for new information or unique events
- Ex. Entering a VHS tape into a VHS reader allows you to listen to old recordings 
- Ex. Buttons for lights
- Ex. Interacting with home phone reads out all the voicemails left while sister/mom were away
- Object Inspection mode
- Certain objects rotates by mouse movement when looking at it
- Other objects, Readable Objects, do not rotate but stay static and are zoomed in at, usually for reading. They also may have multiple pages which can be flipped through via an arrow button in the UI
Puzzles, including solvable locks and keypads
- Doors
- Location aware interaction; opens in or out depending on what side of door you're on
- Blockage aware interaction; if you or an object is in the way of the door opening or closing, the door will stop when it hits its
- VHS tape 
- Inventory
- Collectable Objects
- Those collectables 'unlock' certain interactions (such as a key allowing you to open a previously locked door)
- Journal; a certain tab in your inventory which keeps track of notes or text-based objects you pick up
- Playing movement in 3D
Slow movement (walking), smoothly walking on stairs and sliding on walls
- Sound effects
- Voiceover
Usually event based, when the player finds a certain note or reaches a certain location on the game map a voice reel will play
- Ambient noise (raining, thunder, house noises)
- Lighting
- Game map
- Player
- Can interact with things within a certain range and whilst looking at them
- Can crouch
- Can move
- Non-interactable objects 
- Contributes to Environmental Storytelling
- Ex. scene objects, clues, contextual pieces like news clippings
- Mouselook
- Overarching narrative
- Pause menu
- Options
- Graphics
- Controls
- Etc.
- Map
